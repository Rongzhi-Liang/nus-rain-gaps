# NUS Rain Gaps

Maintained by **Rongzhi Liang** for DEP5118 ITA 3, NUS Master of Urban Planning.

[Project website](https://rongzhi-liang.github.io/nus-rain-gaps/) · [Response map](https://rongzhi-liang.github.io/nus-rain-gaps/map/) · [Report a walking connection](https://nus-rain-gaps.ushahidi.io/post/create/3) · [Request a correction](https://nus-rain-gaps.ushahidi.io/post/create/2)

This independent student prototype documents rain-related gaps in walking connections across NUS Kent Ridge and University Town. It is not an official NUS service or a route safety service.

The current reviewed snapshot contains **five hypothetical demonstrations and zero real observations**. Demonstrations illustrate the reporting process; they are not evidence that an issue occurred. Reports are reviewed before inclusion in the public dataset. Review is not field verification or university endorsement.

## Publication

GitHub Pages hosts the project website and reviewed response map. Ushahidi receives and stores submissions. New submissions await review and do not automatically appear in the website snapshot.

The manually triggered **Publish NUS Rain Gaps** workflow restores a checksum-verified archive containing only the 21 reviewed public website files, then deploys it with the official GitHub Pages actions. The archive contains no private exports, review ledgers, acknowledgement values or credentials. Leaflet's licence and OneMap/SLA attribution are retained.

Editable HTML, CSS, JavaScript and public data are retained with the course project. To update the site, review the source reports, prepare and verify the complete public snapshot, replace the workflow using the maintained release helper, and run the workflow on `main`. After a successful run, verify the formal URL and compare every hosted public file with the release manifest. Do not treat a commit or a success screen on the reporting form as proof of a complete release.
